Como instalar no Windows

O Windows vai mostrar um aviso na primeira vez. É normal e vamos te mostrar como resolver.

⚠️ Não se assuste: todo aplicativo novo no Windows recebe esse aviso do SmartScreen. É seguro. Siga os 2 passos abaixo.

Passo 1 — Clique em "Mais informações"

Quando aparecer a tela azul, clique no link "Mais informações".

Passo 2 — Clique em "Executar assim mesmo"

Depois clique no botão "Executar assim mesmo". O app abre.
